# 💬 Super Support

Du hast eine Frage, ein Problem oder eine Idee? **Ich helfe dir – versprochen.**

## 🚀 Schnellste Hilfe

1. **README lesen** → [Installation & Troubleshooting](README.md#-troubleshooting)
2. **Dashboard → Einstellungen** → Bot-Status, Ollama-Test & Verbindungstest sind dort eingebaut
3. **Dashboard → KI-Prozesse** → zeigt live, was die Moderations-Engine denkt (perfekt zur Fehlersuche!)

## 🐛 Bug gefunden? Feature-Wunsch?

Öffne ein Issue – gerne mit:
- Was hast du getan? Was hast du erwartet? Was ist passiert?
- Konsolen-Ausgabe (Termux) oder Screenshot vom Dashboard
- **Wichtig:** NIE deinen Bot-Token oder `config.json`-Inhalte posten!

→ **[Neues Issue öffnen](https://github.com/Seekseek174/lumiox/issues)**

## ✅ Gute Laune garantiert

- Keine Frage ist zu dumm – jeder hat mal angefangen
- Deutsch oder Englisch, beides gerne
- Feature-Wünsche werden ernst genommen (viele der aktuellen Features kamen von Nutzern!)
